【6. 运行方式】
  环境：Python >= 3.10，仅需 numpy / scikit-learn / matplotlib
        （swanlab 是可选的开发依赖，不进运行时）

  # 1) 安装运行时依赖
  pip install -r requirements.lock

  # 2) 自检（可选）
  python scripts/check_swanlab.py

  # 3) 合成数据闭环（最快，约 3 秒）
  python scripts/run_pipeline.py --dataset synthetic --out out_demo

  # 4) Gas 数据闭环（默认阈值 1.2/2.5）
  python scripts/run_pipeline.py --dataset gas --psi-low 1.2 --psi-mid 2.5 --llm none

  # 5) 跑测试
  python -m unittest discover -s tests -t .

  # 6) 官方数据体检（拿到公开集后）
  python scripts/validate_official.py --root data/official

  参考基线（本包已含实测产物）：
    合成数据    基线 0.498 → 系统 0.836
    Gas 数据    基线 0.283 → 系统 0.731（10 轮 / 0 违规）
