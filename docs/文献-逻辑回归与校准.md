# 文献：怎么让逻辑回归（和我们那个"零成本校准"）更强

> 目的：给 `refresh_normalization` 和 `logreg` 找学术依据与升级方向。
> 结论先给：**我们的"零成本校准"在文献里叫 AdaBN**；**下一步可以升级成 CORAL**。

---

## 一、最重要的发现：我们那一档"校准"是有名字的

`evolver/adapters/model.py` 的 `refresh_normalization()` 做的是：

> 不碰模型权重，只在新批次上重新估计标准化的均值/方差。

这在文献里就是 **AdaBN（Adaptive Batch Normalization）**：

**Li et al., "Revisiting Batch Normalization For Practical Domain Adaptation", ICLR 2017 Workshop**
https://arxiv.org/abs/1603.04779

核心主张：**域偏移时，不需要重新训练权重，只要把归一化层的统计量换成目标域的。**

**为什么这条对我们重要：**

- 我们的实测结论是「重算标准化让 F1 从 0.26 回到 0.60」，原本是个经验发现
- 现在它有了理论支撑：**归一化统计量承载了"数据在哪个范围"的信息，换域时必须换它**
- 答辩时可以说「这一档不是我们拍的，是 AdaBN 的做法」

**它同时解释了我们踩过的另一个坑**：续训时如果只接着训、不刷新标准化，结果反而更差
（254ms / 0.795 vs 75ms / 0.805）。因为权重是配着旧统计量训出来的，
**按 AdaBN 的观点，统计量必须先行更新**。

---

## 二、下一步的升级方向：CORAL（对齐二阶统计量）

**Sun & Saenko, "Deep CORAL: Correlation Alignment for Deep Domain Adaptation", ECCV 2016**
https://arxiv.org/abs/1607.01719

核心主张：域偏移不只是**均值/方差**变了，**协方差结构**也变了；
只对齐边缘统计量不够，还要对齐二阶统计量（协方差矩阵）。

**我们现在的做法 = 只对齐边缘（逐特征标准化），没有管特征之间的相关性。**

我们的气体数据有 128 个传感器，**它们之间高度相关**。如果漂移改变了相关结构
（比如两个传感器同时老化，相关性变强），单靠标准化抓不到——这正是 PSI 的
另一个已知弱点（"只测边缘分布，测不到相关结构变化"）。

**可落地的升级（成本仍然远低于重训）：**

```
现在：x' = (x − μ_new) / σ_new              ← 逐特征，忽略协方差
CORAL：x' = (x − μ_new) · Σ_new^(-1/2) · Σ_ref^(1/2)   ← 白化再重着色
```

代价是一次协方差矩阵求逆（128×128 约 2 ms 量级），**仍属"廉价档"**。
风险：样本少时协方差估计不稳（445 条估 128×128 协方差，条件数会很差），
需要加收缩估计（shrinkage，即 Ledoit-Wolf）。

**建议：先记录为待办，不在校赛前实现。** 因为它需要新的实验验证，
而校赛只剩两天；写进"下一步"比匆忙上线更稳妥。

## 三、协变量漂移下的样本加权（重要性加权）

**Sugiyama et al., "Direct Importance Estimation with Model Selection and Its
Application to Covariate Shift Adaptation", NeurIPS 2007**

核心主张：训练样本来自旧分布、测试来自新分布时，按**密度比**给训练样本加权，
让"更像新数据"的旧样本获得更高权重。

**我们现在的做法**：`recent_window(tau=0.5)` —— 按**时间**给权重，越近的批次权重越高。

**差别**：重要性加权按**相似度**给权重，不是按时间。理论上更准，但需要估计密度比
（多一个模型，且在小样本上不稳）。

**判断：不做。** 我们的时间衰减已经是它的粗糙版本，而密度比估计在小样本上的
方差可能比它带来的偏差还大。**这是一条"知道有、但主动不用"的路线。**

## 四、试过但无效的（记录下来，防止重复劳动）

在气体（445 条训练）和轴承（123 条训练）上实测，**单批 F1**：

| 方法 | 气体 | 轴承 | 结论 |
|---|---|---|---|
| 逻辑回归（默认 C=1.0） | 0.263 | 0.189 | 基准 |
| **L2 加强正则 C=0.01** | **0.378** | 0.169 | 单批提升，**但闭环反而变差** |
| 弹性网（L1+L2） | 0.20~0.27 | 0.17 | 更差，而且慢 20 倍 |
| 类别权重平衡 | 0.266 | 0.189 | 无变化 |
| PCA(20) + 逻辑回归 | 0.285 | 0.189 | 无实质提升 |
| SGD（在线学习） | 0.408 | 0.170 | 单批最高，但闭环未验证 |

**最重要的一条负面结果**：C=0.01 让气体单批从 0.263 升到 0.378（+44%），
但**放进完整闭环后分数从 0.776 掉到 0.658**。

原因：正则化太强会让模型对"重算标准化"和"续训"这两档更新**变得不敏感**，
等于把便宜手段废掉了。

**这是第二次遇到"局部指标 ≠ 全局表现"**（第一次是 GBDT 单批更准但闭环更差）。

## 五、一句话总结

| | 结论 |
|---|---|
| 我们的"零成本校准" | = **AdaBN**，有文献支撑，可以放心讲 |
| 下一步升级 | **CORAL**（对齐协方差），待办，不急于上线 |
| 样本加权 | 有更理论化的做法（重要性加权），**主动不用** |
| 加强正则 / 弹性网 / PCA | 单批可能有用，**闭环里没用**，已实测 |
