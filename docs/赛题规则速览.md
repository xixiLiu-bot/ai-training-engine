# 第二屆北京市大学生"人工智能+"创新大赛 · 赛题规则速览

> 来源：《赛题规则》PDF（5 页，封面 + 正文 4 页）· 命题企业：软通计算机有限公司、华为技术有限公司
> 赛题名称：**"智训引擎"——工业制造场景下的模型训练与超参数优化**
> 实际赛题内容：**工业模型自进化系统（受控 RSI）**

## 一、赛题本质（一句话）

在**会漂移的工业数据流**上，构建一个**无人干预**的系统，自动完成
「漂移监测 → 诊断归因 → 实验优化 → 评估上线 → 回滚」闭环，
在**有限算力/标注/Token 预算**下**长期维持并提升**模型性能。

## 二、两个核心任务

| 任务 | 要求 |
|---|---|
| 任务 1 系统开发 | 基于官方数据包公开部分（训练集/验证集/评测脚本），完成系统开发、训练、调优。须具备自动闭环能力；鼓励「模型层自迭代 + 策略层自改进」两层自进化（受控 RSI） |
| 任务 2 记录与提交 | 所有训练/微调/调整/评估实验按《实验记录规范》上传云端（SwanLab）；提交**系统镜像**（含模型配置 + Harness），驱动 Harness 的大模型必须是 PyTRiO 训练所得模型 或 PyTRiO 的 Qwen3.8-27B |

## 三、交付物（3 项）

1. 模型配置 + Harness 的**系统镜像**（Docker）
2. 云端实验记录链接/查询依据（SwanLab）
3. **系统运行说明文档**

## 四、评测方式

- 组委会在**指定设备、统一离线环境、资源受限**下运行镜像
- 数据：**隐藏测试流**（不公开），模拟持续漂移
- 要求：**全程无人工干预**，自主运行并按时输出
- 若因系统自身原因失败，可申请**重跑 1 次**，取两次较高分

## 五、评分构成（关键：不是纯精度赛）

- **客观分**：平台自动计算，考察**单位增益所消耗的**
  - GPU 时长 / 训练额度
  - 标注配额
  - 大模型 Token
  - → 本质是 **Δ性能 / Δ成本** 的效率比
- **主观分**（专家独立打分）：方法设计与技术路线、实验规范与分析深度、安全可控与工业落地、报告与答辩
- **排名**：客观分排行前 20 → 线下演示答辩

## 六、三条基础门槛（不满足不进排名）

1. 封闭评测中**无人工干预完成全部阶段**并按时输出结果
2. 全部实验按《实验记录规范》**完整留存**
3. 封闭评测**综合性能不低于静态基线**（部署后不再更新的模型）

## 七、赛程

```
高校预选推荐（各校自办，每校 ≤5 支）
   └→ 企业分赛场 · 第一阶段：线上提交镜像 + 客观自动评测
        └→ 第二阶段：线下评审，前 20 支演示答辩
             └→ 北京市线下总决赛（组委会另行通知）
```

## 八、参赛与资源

- 3—5 名本科生，北京地区高校，每人仅 1 队，指导教师 ≤2 人
- Python ≥3.10；框架不限；官方数据包**规模小、含预提取特征**，基础任务**普通 CPU 即可**
- **PyTRiO**：模型训推额度，**仅企业赛阶段提供**（校选不提供）
- **SwanLab**：云端实验记录，已上线免费开放，**校选阶段即可注册**
- 专属评测平台：预计 **11 月初**上线，公开集随平台同步开放；账号与额度最迟**企业赛开赛前一周**发放

## 九、红线

- 妥善保管记录平台账号，不得泄露/转借
- 禁止攻击评测平台、禁止获取隐藏测试集
- 系统须有**受控机制**，防止无限制恶意迭代
- 禁止恶意代码、禁止未授权外部网络访问
- 作品须原创；引用开源框架/预训练模型须遵守许可证

## 十、待向赛题组确认（答疑群二维码见 PDF 第 5 页）

1. 漂移类型定义：协变量漂移 / 概念漂移 / 两者混合？是否有突变 + 渐变？
2. 评测指标与计算方式（F1？MAE？按阶段平均还是最终值？）
3. 资源限制的具体数值（GPU/CPU 时长、显存、单次运行总墙钟时间）
4. 评测期间是否允许调用大模型推理？Token 是否计入成本？上限多少？
5. 隐藏测试流的长度与阶段划分（是否可见逐步反馈？能否在线提交预测拿分？）
6. 静态基线的具体分数与模型形式（用于校准"不低于基线"）
7. 标注配额如何计量（可否申请"标注"动作？成本单价？）
8. 镜像的硬件/网络约束（可否预置模型权重、是否只读文件系统、可否持久化状态）
