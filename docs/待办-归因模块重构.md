# 待办：归因模块重构（交给算法同学）

> 状态：**未实现**，想法已记录。
> 优先级：高（这是分数的天花板）
> 预估：约 2 小时
> 负责人：算法同学

## 为什么要改

现在的 `evolver/loop/diagnose.py` 只有两行启发式：

```python
if psi_mean < 阈值:      → stable
elif label_psi >= 0.1:   → concept
else:                    → covariate
```

**在气体数据上几乎每次都判 `concept`，但那是误判。**

真实原因：第 4 批里没有第 6 类气体（74 条 → 0 条），`label_psi` 因此飙到 2.4。
这是**采样方案不同**，不是概念漂移。

## 核心错误

> **`label_psi` 高，不等于概念漂移。**

| 现象 | label_psi | 是概念漂移吗 |
|---|---|---|
| 这批没测第 6 类 | 高 | ❌ 不是，只是类别构成变了 |
| 判定标准改了 | 可能不变 | ✅ 是，但 label_psi 看不出来 |

**两个方向都会误判。**

## 改法

### ① 加分组 PSI（核心）

按类别分组，**类内各算 PSI 再平均**。类别样本 < 20 条时跳过并标记「样本不足」。

可直接复用 `evolver/loop/monitor.py` 里的 `_psi()`。

实测差异（气体 batch_01 → batch_04）：

```
全局 PSI  = 4.38
分组 PSI  = 8.25   ← 同类气体内部漂得更多
```

**分组后更高，说明漂移不是类别构成造成的假象。**

### ② 四类判别

| 全局 PSI | 分组 PSI | 标签分布 | 判成 | 该做什么 |
|---|---|---|---|---|
| 低 | 低 | 稳定 | 无漂移 | 不动 |
| 高 | 低 | 稳定 | 协变量漂移 | 校准 |
| 高 | 高 | — | 概念漂移 | 重训 |
| 低 | 低 | **高** | **采样变化**（新类型） | 不动 / 重标定权重 |

### ③ 用实验结果确认

每次校准/重训后，把实际增益写回归因结论：

```json
"attribution": {
  "guess": "covariate",
  "confirmed": "concept",
  "evidence": {"calib_gain": 0.01, "refit_gain": 0.42}
}
```

答辩价值：**"我们的系统不猜，它做完实验再下结论。"**

## 验收标准

在气体数据上跑：

- `concept` 的比例从「几乎全部」降到合理水平
- 出现 `采样变化` 这个新类型
- 决策日志里能看到「猜错了 → 实验纠正」的记录

## 提醒

**别做过头。** 归因可以无限精细（对抗验证、MMD、条件分布检验），但它只影响「选哪档动作」。

80 行把准确率从 50% 提到 75% 是好投资；再往 90% 走，收益急剧下降。

**先做 80 行版本，跑出数据再决定要不要深挖。**
